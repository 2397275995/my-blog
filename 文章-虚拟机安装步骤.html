从零装一台虚拟机：VMware Workstation Pro + Ubuntu 26.04 LTS

作者：李旭阳 2026 年 11 月 1 日 分类：虚拟化 约 9 分钟阅读

虚拟化是运维的基本功。这篇从零开始，把在 Windows 上用 VMware Workstation Pro 装一台 Ubuntu 26.04 LTS 虚拟机的完整流程走一遍：装工具、验镜像、配硬件、装系统、装完之后的必要优化，以及新手最容易卡住的几个地方。

跟着做完大概 40 分钟，其中一半时间在等下载和安装。做完你会得到一台能 SSH 登录、能拍快照、随时可以推倒重来的 Linux。

一、动手前先确认三件事

很多人装到一半失败，问题都出在动手之前。

1. CPU 虚拟化有没有开

Windows 下按 Ctrl+Shift+Esc 打开任务管理器，切到「性能 → CPU」，右下角看「虚拟化」是不是「已启用」。如果是「已禁用」，需要重启进 BIOS/UEFI，找到 Intel VT-x（Intel 平台）或 SVM / AMD-V（AMD 平台）打开。

2. 内存够不够分

  • 宿主机 16 GB：给虚拟机 4 GB，剩 12 GB 自己用，比较舒服。
  • 宿主机 8 GB：给 2 GB，并且装 Server 版（无图形界面）。
  • 底线是宿主机至少留 4 GB 给系统，不要把内存分满。

3. 磁盘放哪

别把虚拟磁盘放在 C 盘。一台 Ubuntu Server 建议预留 40 GB，桌面版 60 GB 起。VMware 的虚拟磁盘是「用多少长多少」，但上限要在建的时候给够——后期扩容比一开始就给足麻烦得多。

二、安装 VMware Workstation Pro

Workstation Pro 从 2024 年 11 月起对个人和商业用户都免费，不需要许可证密钥，也不用担心试用期。当前主线版本是按「年份 + 半年」命名的 26H1。

下载

要在 Broadcom 的支持站点下载，需要先注册一个免费账号：

  • 注册：profile.broadcom.com/web/registration
  • 登录后打开免费下载页：support.broadcom.com/group/ecx/productdownloads?subfamily=VMware Workstation Pro&freeDownloads=true

展开「VMware Workstation Pro 26H1 for Windows」，选最新版本号。先把 Terms and Conditions 点开读一遍（不点开没法勾选同意），勾上 I agree，右侧下载按钮才会亮。

安装时唯一要小心的地方：Hyper-V 冲突

如果安装向导提示检测到 Hyper-V，会让你二选一：

  • 自动安装 Windows Hypervisor Platform（WHP）：保留 Hyper-V，VMware 通过 WHP 运行。装完能用，性能略降，但不用改系统设置。选这个最省事。
  • 关闭 Hyper-V：性能最好，但要用管理员权限执行 bcdedit /set hypervisorlaunchtype off，并在「启用或关闭 Windows 功能」里取消勾选「Hyper-V」「虚拟机平台」「Windows 虚拟机监控程序平台」，然后重启。

如果只是想学 Linux，选第一个就行，不要为了几帧性能把 Docker Desktop 和 WSL2 弄坏。

三、下载并校验系统镜像

示例用 Ubuntu 26.04 LTS（2026 年 4 月发布的长期支持版）。文件名里 live-server 是服务器版，desktop 是桌面版，amd64 是 64 位 x86。

国内建议直接从镜像站下载，速度差好几倍：

  • 清华 TUNA：mirrors.tuna.tsinghua.edu.cn/ubuntu-releases/26.04/
  • 阿里云：mirrors.aliyun.com/ubuntu-releases/26.04/

下完一定要校验 SHA256。这一步看着多余，但能挡掉下载中断导致的镜像损坏——那种情况装到一半才报错，排查起来非常费时间。

# Linux / macOS / Git Bash
sha256sum ubuntu-26.04.1-live-server-amd64.iso

# Windows PowerShell
Get-FileHash .\\ubuntu-26.04.1-live-server-amd64.iso -Algorithm SHA256

把输出和镜像站同目录下 SHA256SUMS 文件里的值对一下，一致就说明文件完整。

四、新建虚拟机

Workstation 里点「文件 → 新建虚拟机」，选「自定义」而不是「典型」。典型模式会替你定好一堆参数，其中磁盘控制器和网络模式往往不是你要的。

硬件怎么给

  • CPU：2 核起步，别超过物理核数。
  • 内存：Server 版 2 GB 够用，Desktop 版 4 GB 起。
  • 磁盘：40 GB，存储方式选「拆分成多个文件」，方便以后把整个目录拷到别的机器。
  • 磁盘类型：NVMe 或 SCSI 都行，NVMe 略快。

网络模式怎么选（这一步最容易选错）

  • NAT（VMnet8）：虚拟机借宿主机上网，宿主机能主动连虚拟机，外网连不进来。新手建议默认选它，最省心。
  • 桥接（VMnet0）：虚拟机相当于局域网里一台独立机器，和宿主机平级，路由器会给它单独分 IP。适合模拟「真实服务器」或者从别的设备访问它。
  • 仅主机（VMnet1）：只能和宿主机通信，完全隔离。适合做实验，不怕污染生产网络。

NAT 模式默认网段是 192.168.x.0/24，网关是 x.x.x.2，DHCP 从 .128 开始分配。这些可以在「编辑 → 虚拟网络编辑器」里改。

挂载 ISO

在虚拟机设置的「CD/DVD」里选「使用 ISO 映像文件」，指向刚下载的 iso，「启动时连接」要勾上。

五、安装系统

开机后进入安装器，按顺序走：

  • 语言：服务器建议选 English。选中文会出现半屏中英混杂，后期 locale 也容易出问题。
  • 键盘布局：默认 English (US)。
  • 安装类型：Ubuntu Server。
  • 网络：默认 DHCP，屏幕会显示分到的 IP，记下来。
  • 代理：留空。
  • 镜像源：可以在这里直接改成 mirrors.aliyun.com/ubuntu，比装完再改省一步。
  • 存储：Use an entire disk，并勾选 Set up this disk as an LVM group。LVM 的好处是以后扩容不用重装。
  • 用户：填主机名、用户名、密码。密码别设太简单，后面 sudo 要用。
  • SSH：务必勾选 Install OpenSSH server。这一步不勾，装完只能对着 VMware 窗口敲键盘，连复制粘贴都费劲。
  • 预装软件：不选，需要什么自己装。

装完重启。VMware 会提示「请移除安装介质后按回车」，直接回车，它会自动断开 ISO，从硬盘启动。

六、装完必做的五件事

1. 装 open-vm-tools

这是 VMware 官方的客户机工具，负责时间同步、关机信号、共享文件夹。

sudo apt update
sudo apt install -y open-vm-tools open-vm-tools-desktop

服务器版装 open-vm-tools 就够；桌面版加上 desktop 包才有剪贴板共享和自适应分辨率。

2. 换国内 apt 源

Ubuntu 24.04 之后源配置改成了 deb822 格式，文件是 /etc/apt/sources.list.d/ubuntu.sources，已经不是以前的 sources.list 了。

sudo cp /etc/apt/sources.list.d/ubuntu.sources /etc/apt/sources.list.d/ubuntu.sources.bak
sudo sed -i 's|http://archive.ubuntu.com/ubuntu/|https://mirrors.aliyun.com/ubuntu/|g' /etc/apt/sources.list.d/ubuntu.sources
sudo sed -i 's|http://security.ubuntu.com/ubuntu/|https://mirrors.aliyun.com/ubuntu/|g' /etc/apt/sources.list.d/ubuntu.sources
sudo apt update

3. 配静态 IP（NAT 模式下可选）

DHCP 分到的地址每次开机可能变，SSH 客户端就要跟着改配置。把它固定下来：

sudo nano /etc/netplan/50-cloud-init.yaml
network:
  version: 2
  ethernets:
    ens33:
      dhcp4: false
      addresses:
        - 192.168.100.10/24
      routes:
        - to: default
          via: 192.168.100.2
      nameservers:
        addresses: [223.5.5.5, 119.29.29.29]
sudo netplan apply

注意三点：网卡名先用 ip -br a 看一眼，可能是 ens33、ens160 或 ens37；网关填你在「虚拟网络编辑器」里看到的值，不要随手写；gateway4 的写法已经废弃，要用上面的 routes。

4. 验证 SSH

systemctl status ssh
ip -br a
ssh 你的用户名@192.168.100.10

5. 时间同步

timedatectl set-ntp true
timedatectl status

虚拟机挂起再恢复后时间容易漂，装好 open-vm-tools 一般就正常了。

七、快照：给自己留一颗后悔药

这是虚拟机相对真机最大的好处。

  • 拍快照：虚拟机 → 快照 → 拍摄快照。装软件、改配置之前拍一个，改坏了 10 秒回到原样。
  • 克隆：虚拟机 → 管理 → 克隆。完整克隆是独立副本，链接克隆省磁盘但依赖父虚拟机。

一个建议：装完系统、配好网络和 SSH 之后，先拍一个叫「干净系统」的快照，再做其他实验。以后所有乱七八糟的尝试，都从这个快照分叉出去。

克隆之后记得改机器标识，否则两台机器的 machine-id 和 IP 会打架：

sudo rm /etc/machine-id
sudo systemd-machine-id-setup
sudo hostnamectl set-hostname node2

八、常见问题速查

提示「此主机支持 Intel VT-x，但 Intel VT-x 处于禁用状态」

进 BIOS 打开虚拟化。如果 BIOS 里已经开了还报这个错，检查 Windows 是否开着「内核隔离 → 内存完整性」，把它关掉再重启。

装完开机黑屏或分辨率不对

虚拟机设置里关掉「加速 3D 图形」，显存调到 4 GB 以上。桌面版装完 open-vm-tools-desktop 后分辨率会自适应窗口。

虚拟机能上网，但宿主机 SSH 连不上

  • 确认装系统时勾了 OpenSSH server，或手动补装：sudo apt install -y openssh-server
  • 确认 NAT 模式下虚拟机 IP 是 192.168.x.x 网段，宿主机连的是这个地址
  • Windows 服务里检查「VMware NAT Service」和「VMware DHCP Service」是否在运行，这两个服务挂了 NAT 就废了
  • 虚拟机里查防火墙：sudo ufw status

磁盘不够了

先在 VMware 里扩容虚拟磁盘，再进系统把分区撑开。用了 LVM 的话：

sudo growpart /dev/sda 3
sudo pvresize /dev/sda3
sudo lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv
sudo resize2fs /dev/ubuntu-vg/ubuntu-lv

复制粘贴和拖拽文件不生效

服务器版没有图形界面，本来就没有剪贴板共享，用 SSH 就好。桌面版装 open-vm-tools-desktop 后，在 VMware 设置里把「客户机隔离」的复制粘贴勾上。

九、小结

整个流程可以压缩成一句话：确认硬件虚拟化 → 装 Workstation → 验镜像 → 自定义建机（NAT）→ 装系统时勾 SSH → 装 open-vm-tools → 拍快照。

真正容易出问题的不是安装本身，而是前面几个决定：内存分多少、磁盘放哪、网络用哪种模式、装系统时有没有勾 SSH。这几步想清楚了，后面基本一路顺。
